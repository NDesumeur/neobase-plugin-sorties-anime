# Sorties anime

Toutes les sorties d'animes, jour par jour, pas seulement les tiennes : suis ceux que tu veux et ajoute leurs sorties à ton emploi du temps, remises à jour automatiquement.

Ses données sont rangées dans le dossier du plugin, que NeoBase sauvegarde (synchro cloud comprise). Au premier lancement, il reprend ce que tu avais déjà dans NeoBase.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Sorties anime → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
